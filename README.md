# Artifact for NOC-NOC

This repository contains all the artifacts for our SIGMOD'24 paper "NOC-NOC: Towards Performance-optimal Distributed Transactions."

This work aims at proposing a new design objective for the design of distributed algorithms which optimises both read and write transactions. To test such proposal, two separate algorithms are designed and their performance is measured: RA-NOC2 and Eiger-NOC2.

Checkout the individual folder for more information about the individual algorithms.

Remark: as the transactions are generated with a certain degree of randomness in the experiments the results may not exactly match those of the paper but the trends should follow what is depicted in the published work.
